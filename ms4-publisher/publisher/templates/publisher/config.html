Token de Facebook

Cada persona guarda su propio token y página. No tiene que ser de la cuenta con la que iniciaste sesión: pega el Page Access Token de la página a la que quieras publicar, con el permiso pages_manage_posts. Obtenlo en el Graph API Explorer: selecciona tu app, luego tu página y genera el token.

Datos del contest

El contest se elige manualmente. Cada persona configura el suyo (año y número). Es el contest que se usará para generar la tabla de este panel.

Aparece en el texto del post de Facebook.
